# Taskr reference notes (from Vy's screenshots)

Working notes collected before the next round of changes. Not final.

## Look and feel
- Target tone: like fabriccapture.com. White background, black primary buttons, grey borders and secondary text, U icon mark top left. Neutral only.

## My Day table
- Drag handle on each row for manual ordering.
- Play button inside the title cell to start the timer on that task. Running row shows a marker at the left edge.
- DAILY tag next to titles for repeating tasks.
- Priority is a number (e.g. 1.5, 2.5, 3.0) with a dropdown in the cell. Detail panel shows "Priority (1.0-4.9)" and a label such as "MAJOR GAIN".
- Inline dropdowns in cells: job role, project, priority, assignee, HTC.
- HTC in minutes/hours (15min, 30min, 1h15min).
- Time in shows minutes logged (4min, 22min, 27min).
- Yellow rows = today. Light blue rows at the bottom = unknown, ask Vy.
- Bottom bar: "Show review tasks +594", "Show all active tasks +3".

- Client
- Assignee (name: role list)
- Collaborators
- Assigner
- Priority (1.0-4.9) + gain label
- Complexity (Simple / ...)
- Start date, Due date
- Repeat (Does not repeat / daily / ...)
- Explanation URL
- Status % slider
- Subtasks, Attachments, Required Assets (collapsible)
- Need-to-have / Nice-to-have checkboxes
- Footer: "Logged 0.07h · Est 0.25h · Client: Miscellaneous"
- DONE button at the bottom
